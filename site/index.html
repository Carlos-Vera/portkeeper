No Apple or Microsoft developer certificate yet, so your system warns once. macOS: open, then System Settings → Privacy & Security → Open Anyway. Windows: More info → Run anyway. The one-command install above skips the dialog. Details

Always one click away

Lives in the macOS menu bar or the Windows tray. No Dock icon, no window to lose. Floats over full-screen apps.

Ready when you log in

Turn on Launch at login and Open widget on start, and the list is there as soon as your computer is. New versions install themselves with one click.

Who started it

Walks up the process tree to the agent or IDE: Claude Code, Codex, Cursor, Gemini, Copilot, VS Code and more.

Stop, restart, lock

Stop a project with one click and start it again later. Lock the one a client is using so nobody stops it.
